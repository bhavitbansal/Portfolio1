Project Overview

This personal portfolio was engineered as a digital showcase reflecting both engineering discipline and UI design intuition. It presents technical capabilities alongside personal interests in systems thinking and cricket biomechanics.

Built entirely without third-party CSS or JS frameworks, it demonstrates mastery over foundational web technologies, custom CSS variable tokens, and responsive layout architectures.

Problem Statement

Developer portfolios often rely heavily on multi-megabyte JavaScript single-page application frameworks, causing slow first-contentful-paint times, layout shift instability, and generic component aesthetics.

The goal was to construct a fast, sub-second loading web experience that balances subtle interactive canvas animations with clear editorial typography and WCAG accessibility standards.

Solution

Established a centralized CSS design token architecture known as the Bloom Palette (`--bg-primary: #FFF7FC`, `--accent-purple: #A855F7`), pairing soft lavender glassmorphic cards with responsive CSS Grid layouts.

Integrated a lightweight mathematical Marching Squares algorithm on an underlying HTML5 Canvas element to generate ambient, real-time topological contour lines that interact subtly with cursor movements.

Technologies Used

HTML5 Semantic Structure CSS3 Custom Properties Glassmorphism UI Vanilla JavaScript (ES6+) Marching Squares Algorithm Simplex Noise Field

Challenges & Engineering Solutions

Canvas Battery & GPU Optimization: Continuously evaluating noise grids on mobile displays can degrade battery life. Solved by implementing dynamic step-size scaling on small viewports and binding a visibilitychange event listener to pause rendering cycles whenever the tab is unfocused.

Interactive Terminal System: Building a command-line interface in pure JS required parsing string commands, output history DOM appending, and auto-scrolling terminal containers without causing layout shifts.

What I Learned

Designing this portfolio reinforced the value of constraint-driven engineering—proving that high visual polish and interactive depth can be achieved using lean native web standards.
