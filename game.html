01 • Overview

The Game Experience

The Browser Arcade Game was created to deliver an engaging arcade experience right inside the browser window without downloading external plugins or third-party engines. It combines fluid player movement, dynamic obstacle scaling, real-time spatial collision checks, and continuous score tracking into a cohesive experience.

Built entirely using the native HTML5 Canvas API and structured Vanilla ES6+ JavaScript, the software achieves sub-millisecond input responsiveness and smooth animation rendering. Every mechanics pipeline—from sprite transformations to particle trail rendering—was engineered by hand to demonstrate frontend performance control.

02 • Personal Intent

Why I Built This

I wanted to build a project where performance wasn't an afterthought—it was the core product requirement. While web frameworks streamline typical UI layout creation, game development forces you to understand low-level browser mechanics: garbage collection spikes, event loop scheduling, and GPU layer acceleration.

I set out to build a game engine without reaching for Phaser or Unity WebGL. I wanted to master mathematical hitboxes, dynamic delta-time loops, and clean JavaScript architecture from first principles.

03 • Architecture

Engineering Highlights

⚡

Custom Game Loop

Driven by requestAnimationFrame with time-delta calculations to ensure game speed remains identical across 60Hz and 144Hz monitors.

🎯

Collision Detection

Utilizes Axis-Aligned Bounding Box (AABB) math with sub-step segment checking to prevent fast entities from skipping through hitboxes.

🎨

Animation System

Lightweight particle generation pipeline and canvas clearing algorithms optimized to maintain smooth frame rates on mobile GPUs.

📱

Responsive Controls

Unified input listener handling keyboard WASD/arrow bindings alongside passive mobile touch-swipe controls with 0ms latency.

🏆

Score Management

Persistent local storage integration tracking high scores, difficulty scaling thresholds, and active multiplier combos.

⚙️

Performance Optimized

Implements an Object Pool pattern for projectiles to eliminate dynamic memory allocation and garbage collection pauses during gameplay.

06 • Problem Solving

Engineering Challenges

⚠️ High-Refresh Rate Speed Glitch

Challenge
Game physics ran twice as fast on 144Hz screens compared to standard 60Hz displays.
Why It Happened
The render loop applied fixed pixel increments per frame tick rather than measuring delta time.
How I Solved It
Calculated millisecond elapsed deltas between frame loops and scaled velocity vector multipliers.
What I Learned
Hardware independence is essential for deterministic game physics on the web.

⚠️ Garbage Collection Stutter

Challenge
Occasional micro-stutters interrupted 60 FPS rendering during intense gameplay sequences.
Why It Happened
Spawning and destroying projectile objects continuously triggered V8 engine garbage collection.
How I Solved It
Implemented a fixed-size Object Pool array that reuses projectile memory references.
What I Learned
Memory allocation patterns directly dictate real-time JavaScript performance.
